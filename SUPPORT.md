# Support

Calcifier is an open source project provided without a support SLA.

- Use GitHub issues for reproducible bugs and focused feature requests.
- Include the Calcifier version, Python version, operating system, command,
  expected result, and a minimal reproduction.
- Remove secrets, prompts, private source code, customer data, and sensitive
  trace content before posting.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

The latest released minor version and `main` are supported. General questions
may be answered when maintainer capacity allows, but response times are not
guaranteed.
