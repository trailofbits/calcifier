# Style review

Check a document against the house style so authors get specific, actionable fixes.

## References

- [Style guide](references/style-guide.md): the rules every document follows.
- [Examples](references/examples.md): before-and-after rewrites.

## Procedure

1. Read the style guide and the examples.
2. Review the document against every rule.
3. Return each problem with the rule it breaks and a suggested rewrite.
